Proyecto académico

Consultas SQL sobre una biblioteca

Escribí una consulta y ejecutala. El SQL se analiza y se resuelve enteramente en tu navegador: no hay servidor ni base de datos detrás, y tampoco librerías externas. El motor está escrito en JavaScript para este demo y vive en sql.js.
